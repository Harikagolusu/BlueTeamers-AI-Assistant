# Future Roadmap

The Enterprise Tool Library establishes a solid, abstracted foundation. The following enhancements are planned for future modules. **Note:** These are planned integrations and expansions, not current scope.

## Providers
- **Live FAISS Provider**: Connecting `ISearchProvider` to localized, in-memory FAISS vector indices for hyper-fast semantic RAG retrieval.
- **OpenSearch Provider**: Enterprise distributed vector search integration.
- **VirusTotal Provider**: Integrating `IThreatIntelProvider` with VT APIs for live hash and URL reputation lookups.
- **MISP Provider**: Open-source threat intelligence sharing platform integration.

## RAG & Search Expansions
- **Hybrid Retrieval**: Enhancing the `Retriever` to merge sparse (BM25) and dense (Vector) search results.
- **LLM Reranking**: Substituting the simple `Ranker` with an LLM-driven contextual cross-encoder reranker.

## Architecture Integrations
- **OpenTelemetry Exporter**: Exporting standard metrics and distributed traces generated by the `BaseService` lifecycle hooks.
- **Streaming Responses**: Refactoring `ResponseBuilder` to emit asynchronous SSE streams for high-latency tools.
- **MCP Server Integration**: Exposing the entire Tool Registry over the Model Context Protocol.
- **Multi-Agent Orchestration**: Providing this exact Tool Framework as the foundational capability layer for specialized, autonomous sub-agents.
