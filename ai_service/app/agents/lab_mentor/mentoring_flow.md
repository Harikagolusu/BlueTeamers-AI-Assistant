# Mentoring Flow

The mentoring flow ensures learners are supported without being spoon-fed.

- **Level 1 Hint**: General concept nudge ("Have you considered how SQL handles string concatenation?").
- **Level 2 Hint**: Directional nudge ("Look closely at the input fields in the login form.").
- **Level 3 Hint**: Actionable nudge ("Use a proxy tool to intercept the request and modify the parameter.").

If a learner repeatedly requests hints, the system escalates automatically to Level 3. However, flags are strictly forbidden.
