# Assessment Flow

The Assessment Flow is a 14-step DAG managed by `WorkflowBuilder`.

1. Understand Request
2. Retrieve Historical Assessments (Collaborate with Learning Coach)
3. Retrieve Competency History (Collaborate with Learning Coach)
4. Evaluate Knowledge
5. Evaluate Practical Skills
6. Evaluate Scenario Responses
7. Compute Competencies
8. Detect Skill Gaps
9. Generate Adaptive Questions
10. Generate Feedback
11. Compute Readiness
12. Generate Recommendations
13. Update Analytics
14. Store Memory
